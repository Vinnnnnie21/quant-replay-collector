# Apply the entry-modeling discipline to exit decisions

The v1.6 exit-behavior model uses explicit EXIT_NOW versus HOLD judgments and adds named position-path state features to the same constrained elastic-net workflow used for entry behavior. It inherits the 30-per-class induction gate, compact-feature cap, training-only robust normalization, class weighting, regularization search, episode-pure expanding validation, stable-coefficient rule, recall-constrained research threshold, final-test minimums, and immutable user-triggered versions. Reusing one discipline limits model-family experimentation, but keeps entry and exit evidence comparable and avoids a second, weaker validation standard.
