# Separate structural retrieval, human behavior modeling, and strategy validation

v1.6 uses an interpretable, reproducible structural-similarity metric to retrieve review candidates instead of chart-image embeddings or an opaque learned score. During the similarity stage, normalized features are averaged within four equally weighted market-structure groups: price path, candle shape and range position, trend and volatility, and trading activity and aggressor direction. Decision and higher-timeframe market structures contribute 60%, 25%, and 15%; their combined distance contributes 90% of total distance, while calendar-time distance is computed once and contributes 10%. The nearest three confirmed ENTRY samples form the retrieval score. Each timeframe uses fixed 5-, 20-, and 60-bar scales; individual Setups cannot tune these scales to historical results. Price-path features use ATR-normalized fixed anchors: 5 points for the 5-bar scale, 10 for 20 bars, and 15 for 60 bars; scale distances are averaged equally without time warping. Structural distance uses fixed, feature-specific scales rather than sample-fitted normalization, so adding samples does not rewrite old pairwise scores. The later behavior model uses a separate compact set of named features, never raw anchor coordinates, with feature count capped at `min(12, floor(minority-class count / 5))`; robust normalization and feature selection are fitted only inside training data. Weights, scales, and anchor definitions are versioned and historical scores from different formula versions are not compared. Neither retrieval nor behavior scores are presented as profitability; strategy effectiveness requires later out-of-sample outcome validation. This creates more named outputs and versioning work, but prevents one impressive-looking number from mixing resemblance, personal behavior, and financial performance.
