# Quant Replay Collector v1.6.0 发布说明

v1.6.0 把交易回放中的主观开仓、平仓行为接入统一的“决策研究”工作区。它仍是本地研究工具，不接真实下单 API，不输出买卖信号，也不保证盈利。

## 本版内容

- 新增唯一的“数据分析 → 决策研究”入口，开仓和平仓共用两标签、五步骤和三周期上下文。
- 新增不可变策略模板版本：方向、决策协议、规则和三个周期保存后只能通过新版本改变。
- K 线缓存持久化计价币成交额、成交笔数、主动买入基础币数量和主动买入成交额；缺失与真实零分开保存。
- 新增三周期完整度检查、最小区间补齐、进度、取消、重试和正式研究操作门控。
- 新增跨品种、跨周期的独立行情片段分组及可审计人工修正。
- 新增开仓与全量平仓的三周期盲审；真实动作不会自动变成人工结论，揭示前服务层移除未来信息。
- 新增结构相似度分解、正式候选扫描和匿名盲审批次。
- 新增可解释的开仓选择倾向与立即平仓选择倾向模型，按时间和独立行情片段验证。
- 新增匹配后的完整 15 项后验矩阵，保留证据不足和非显著结果。
- 新增不可变研究快照、中文结构化报告和受产品边界约束的策略假设卡。
- 完成新增界面汉化、深浅主题、窄窗口、单主滚动区和后台任务安全退出回归。
- 修复主窗口侧栏初始几何、完整度任务终态、绩效曲线交易标记时间位置等 RC 阶段缺陷。

## 数据库与升级

当前数据库 schema 为 19。应用版本 `1.6.0` 与 schema 版本相互独立。旧库升级前会创建备份，迁移只增不删，但迁移是单向的。升级前请退出旧程序并备份完整数据目录；需要回退时恢复对应备份。

正式包、测试和原生冒烟检查不包含、也不应访问仓库中的真实数据库。用户应自行维护数据备份。

## 已知限制

- 平仓研究只处理全量平仓，不研究部分减仓比例。
- 短周期 K 线不是逐笔成交或盘口深度。
- 行为模型描述历史人工选择，不是胜率、盈利概率或交易信号。
- 后验比较未扣全部真实交易成本，不证明策略有效。
- v1.6.0 不生成 PDF 研究报告。

## 风险声明

QRC 不构成投资建议，不自动执行交易，不保证盈利。历史回放、相似度、模型和统计结果都可能受数据质量、样本选择、市场变化和人工标注偏差影响。
